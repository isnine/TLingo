# AGENTS.md

Repository-specific instructions for coding agents. Canonical architecture and workflow details live under [`docs/`](docs/README.md); do not duplicate them here.

## Working Defaults

- Inspect the live repository, Xcode, and simulator state before drawing conclusions.
- Keep changes scoped to the request. Do not refactor adjacent code or create speculative abstractions.
- Do not expose secrets in logs, docs, commits, screenshots, or reports.
- For Apple APIs, use local Xcode documentation before Web research.

## Repository Map

```text
ios/AITranslator/          App lifecycle and platform UI
ios/ShareCore/             Shared translation, realtime, history, auth, billing, and UI
ios/Direct/                Direct distribution and Sparkle
ios/TranslationUI/         System translation extension
ios/TLingoBroadcastUpload/ ReplayKit upload extension
ci_scripts/                Xcode Cloud and Direct release scripts
```

The app schemes are `TLingo` and `TLingo-Direct`. The cloud Worker and Web frontend live in a separate private repository.

## Validation

Use the smallest relevant gate from [`docs/verification.md`](docs/verification.md). Read [`docs/ios-agent-workflow.md`](docs/ios-agent-workflow.md) before building, launching, or runtime-verifying the app.

## Configuration And Secrets

- Built-in actions are defined in `ios/ShareCore/Configuration/BuiltInActionCatalog.swift`.
- `ios/ShareCore/Resources/DefaultConfiguration.json` is only a fallback custom configuration.
- Cloud endpoints and client credentials live in the gitignored `ios/ShareCore/Configuration/AppSecrets.swift`, generated by `ci_scripts/generate-app-secrets.sh` from `TLINGO_*` environment variables. Never commit it.
- Build settings live in `ios/Configuration/Base.xcconfig` and `Direct.xcconfig`.

## Release Guardrails

- App Store iOS and macOS releases are built and distributed only by Xcode Cloud, which owns App Store build numbers.
- `TLingo-Direct` macOS releases are built by the Xcode Cloud `Direct Release` workflow on `v*` tags; see [`docs/direct-release.md`](docs/direct-release.md). `.github/workflows/release-direct.yml` is a manual-only rollback and must never run concurrently with it.
- Routine version bumps update `MARKETING_VERSION`. Update `CHANGELOG.md` before creating a `v*` tag.
- Stage explicit paths and verify `git diff --cached --name-only` before committing.
