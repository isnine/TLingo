# Onboarding design reference (Scenarios + Realtime)

Source: Design canvas "TLingo Onboarding: Scenarios and Realtime"
https://claude.ai/artifact/E5UtQAQCcyxHSaZ99n5Kpd

Each *.dc.html is one board; open in a browser (they load ./support.js which is NOT included,
so read the HTML directly: layout, copy, colors and spacing are all inline styles).
canvas.json lists board positions/titles.

- Main: scenario picker
- Flow / FlowShows: flow charts per selection (Flow row 4 order is outdated: implemented order is Realtime -> Words)
- RT1 Intro, RT2 Languages, RT3a Downloading, RT3b Ready, RT4 Permissions,
  RT5 Speak (microphone), RT5w Watch (iPhone Audio capture), RT6 Done, RT-Denied
